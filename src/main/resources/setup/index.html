Super Bistro setup

This runs once. Super Bistro will create its own database inside your PostgreSQL and then open the order desk.

Step 1 · PostgreSQL

Install PostgreSQL 15 first if you haven't. Use the postgres user and the password you chose while installing it. Super Bistro only uses it to create its own login and database.
